# Blog Manager

## Project Description

Blog Manager is a simple personal blog for students and young professionals. Users can create, read, edit and delete articles. There is no backend: all articles are saved in the browser with `localStorage`.

Main features:

- Create an article with a form
- Edit an article in a modal
- Delete an article with a confirmation
- Search by title, filter by category and sort by date

## Technologies

- React
- TypeScript
- Vite
- React Router
- ESLint
- Prettier

## Installation

